# Compagnon ATDC pour Android — versions publiées

Ce dépôt public ne contient AUCUN code : seulement les versions publiées de l'application Android du **Compagnon du Troquet
Des Copains** (onglet « Releases »), étiquetées `tablette-<version>`.

- **Installer** : sur le PC, dans le Compagnon, application « Tablette » (section « Compagnon ») : visez le QR de
  téléchargement avec l'appareil photo de la tablette, puis ouvrez le fichier téléchargé. Android demande d'autoriser
  l'installation : c'est normal, l'application ne vient pas du Play Store.
- **Mettre à jour** : rien à faire ici. Quand une nouvelle version sort, le Compagnon du PC la propose à la tablette (bandeau
  « Mise à jour disponible », bouton « Installer »).
- **RC** (pré-versions) : proposées aux PC dont le bouton « Beta » du Compagnon est activé ; les autres reçoivent les versions
  officielles.

Android 4.4 et plus. L'application ne fonctionne qu'avec le Compagnon de votre PC, sur le même réseau.
